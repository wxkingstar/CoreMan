# CoreMan Logo

## 已认可的基础版本

2026-09-13，用户认可精修版本，并指定保留为未来 Logo 的基础。

- [v1 矢量源文件](v1/coreman-mark.svg)
- [v1 效果与尺寸预览](v1/preview.html)：单文件 HTML，无外部依赖，可直接打开。
- 当前产品资源：[`web/public/coreman-mark.svg`](../../../web/public/coreman-mark.svg)，由登录页、后台导航和浏览器图标共用。

## 设计基准

- 保留字母 C 与双眼的组合，体现 AI 同事的亲和感。
- 64 × 64 矢量画布，底板圆角 18。
- 松石青底色 `#16756B`，浅白笔画 `#F2F8F3`，青柠点睛 `#C4E58D`。
- C 笔画宽度 6.5，眼睛笔画宽度 4.5，圆点半径 3.25。
- 圆点嵌入 C 的末端，轮廓与眼睛之间保留清晰间距。
- 预览包含浅色、深色背景及 16、24、36、48、64px 尺寸。

## 后续迭代

`v1/` 是已认可版本的归档，后续设计请以它为基础另建版本，不覆盖此目录。
新版本确认后，再更新产品使用的 `web/public/coreman-mark.svg`，并记录对应版本。
