# 使用统计、成本与体检

`GET /api/admin/statistics` 接受 start/end（含首尾日期，最多 366 天）及 timezone（Asia/Shanghai、Asia/Tokyo、UTC），默认最近 30 天。与对话记录使用相同可见范围：自己的对话、所管理机器人、本团队负责人范围；委员会和平台管理员可看全量。每条聚合查询限 5 秒，时间索引并发创建。消息计数包含对话与定时执行记录，未知身份不计入活跃用户；排行最多 50 项。

输入、输出、缓存读、缓存写分别返回汇总值与已计量条数，无记录为 null。成本小计仅含已有估算值，并返回覆盖条数；部分计量不是全量成本。统计不读取或返回对话正文。

`GET/PUT /api/admin/model-prices` 维护 USD / 百万 Token 的价格，按 provider、完整 model 和 UTC 生效日匹配。写入限委员会/平台管理员并校验 If-Match。未预置任何猜测价格。四类用量全部已知且存在当日有效价格才估算，精度保留六位小数；日志写入时固定成本快照，日后改价不回写历史。定时执行使用实际发起时的模型，而非结束时机器人可能已换的新模型。

`POST /api/admin/bots/{id}/health-report` 以已绑定平台身份的机器人管理员发起 SSE 独立会话，session_id 为空，不改正常 ChatSession。请求环境按当下操作者构建，静态环境不可伪造发言者。跨 API 实例最多两个体检、每个 bot 最多一个，最多 300 秒/128 KiB 文本，客户端可中止连接。报告只接收模型正文和工具名，不展示思考过程/工具参数；常见已知凭据值跨分片过滤。输出只作为文本渲染。未收到正常 finish、正文为空或过程中配置变化不会标成功。

体检提示要求只读，但不是外部执行沙箱；底层工具权限仍由实际账号与实例约束。报告中的“正常”是模型解释，不能替代真实业务验证。审计只保存请求人、报告 ID 和终态，不保存正文或凭据。前端展示部分结果和完整完成状态，连接关闭不等于成功。
