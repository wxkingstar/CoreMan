# Workspace runtime protocol 1
All payloads carry trusted working_dir and bot_id. Success results include success=true.
- workspace-info: exists, empty, owned, workspace_protocol=1.
- workspace-init: content optional; preserves existing AGENTS.md, refuses differing AGENTS.md/CLAUDE.md, preserving both for manual merge; same-content CLAUDE.md is preserved as CLAUDE.md.preserved-N; creates relative CLAUDE.md -> AGENTS.md, ownership marker. Refuses another owner's marker.
- workspace-list: path default ''; entries [{name,path,type,size}], max 1000, truncated.
- workspace-read: path, offset=0, length<=262144; returns data base64, content UTF8 or null, size, hash SHA256 of whole file, editable (UTF8 <=1MiB), offset, eof.
- workspace-write: path, content UTF8 <=1MiB, expected_hash required (null means create only); returns hash,size. Canonical CLAUDE.md -> AGENTS.md is editable through AGENTS.md; other symlinks cannot be edited. Hash conflicts return success=false/code=conflict.
- workspace-export: manifest [{path,size,hash,mode}] for regular files and [{path,link}] for safe internal relative links; excluded list. Read individual regular files using workspace-read chunks. Secrets, caches, .git and ownership metadata excluded. Limits 10000 entries, 1GiB total.
- workspace-import: transfer_id UUID or hex/hyphen string length 16..64, manifest REQUIRED first call (may repeat), optional path/data(base64)/offset; first call can initialize only. Staging is a sibling with bot/transfer metadata. Chunks <=256KiB, strictly sequential. Returns received bytes.
- workspace-finish: transfer_id, optional manifest (must match), content optional. Verifies complete staged manifest and SHA256 before atomic rename to absent or empty target, or owned target containing ONLY marker. Never overwrites a nonempty target. Initializes canonical instructions after validation. Returns installed=true.
- workspace-git-status: initialized, branch, head, files[{path,status}].
- workspace-git-test: git_url, branch, git_access_token optional; checks ls-remote; returns reachable=true.
- workspace-git-backup: same config, files REQUIRED explicit safe regular-file paths (deleted paths and canonical CLAUDE.md symlink accepted), message optional. Commit selected files then push HEAD to configured branch without force. Returns pushed=true, head only after push success.
- workspace-git-restore: same config; clone configured branch to owned sibling staging, scrub remote credentials (URL cannot contain credentials), initialize instructions, atomically install into empty/absent target. Returns installed=true,head.
Git URLs use existing configured runtime host allowlist, HTTPS or SSH git@host:repo.git. HTTPS token uses temporary askpass environment only; disabled hooks/credential helpers/interactive prompts, timeouts, generic sanitized errors. Never executes hooks or force push. Existing dirty staged index blocks backup to avoid unintended commit.

Review refinements: ping advertises workspace_protocol=1. Configured directory symlinks below runtime root are rejected. Existing foreign ownership markers block all operations except info. Git status for uninitialized workspaces reports safe files as ??; backup permits empty files for retrying a committed push. First/unborn local repository fetches configured remote branch and resets index/HEAD only (working files preserved), retaining prior remote history. Existing origin must match. Git URL rewrites rejected; protocols restricted to HTTPS/SSH. Finish records transfer_id in ownership marker and succeeds idempotently for the installed same operation; staged matching links are retry-safe.
